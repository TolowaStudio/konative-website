# Contributing

Thanks for helping improve [konative-website](https://github.com/tolowa-studio/konative-website).

## Branch naming

Create a branch from `main` using one of these patterns:

- `symphony/<issue>` — Symphony / Linear trial work (e.g. `symphony/TOL-1906`)
- `feature/<topic>` — product or docs changes (e.g. `feature/readme-local-dev`)

## Pull requests

1. Push your branch and open a **pull request into `main`**.
2. Describe what changed and how you validated it.
3. Tolowa’s **merge app** runs checks, reviews the PR, and merges when approved.

Do not merge or deploy from your machine unless you have an explicit ship gate from Tolowa.
